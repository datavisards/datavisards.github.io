# DataVisards

Website for the DataVisards lab at HKUST: [datavisards.com](https://datavisards.com).

## Develop

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open <http://127.0.0.1:4000>. Pushes to `main` deploy through GitHub Pages.
